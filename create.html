Good to know

The rules every package follows

What ID should my keyboard use?

Use YourName-KeyboardName, for example Riya-PastelSplit: letters, digits or _ on each side of a single dash; 2–24 characters before it and 2–32 after. Names starting with Noky are reserved and can't be used.

What does the verified badge mean?

It marks keyboards made and published by ALLStudio, the studio behind Noky. Community keyboards don't carry it, whatever name they use.

Is my file uploaded when I check it?

No. The check happens right here in your browser. The file is only sent when you press Submit; it then goes into a public pull request on GitHub for review.

What can a keyboard contain?

Anything the Layout Manager can make: multiple layers, the 8 key shapes, gradients, glow, borders, X/Y offsets, rotation, Google Fonts, long-press actions, accent pop-ups, macros and Ctrl/Alt/Fn keys. The live preview here uses the same rules as the app.

How long does review take?

Usually a few days. You get a link to follow your submission, and if you add your GitHub username, GitHub notifies you too. Once approved, your keyboard appears on the Keyboards page with its own share link.
